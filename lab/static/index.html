      What these changes do not stop

      • Differencing. Rounding limits what subtracting two counts can say. It does not end it (question 8).
      • Misuse inside the job. The purpose stops other jobs, not a badly done one (question 12).
      • A patient agent can come back tomorrow, and two can pool what they see (question 11).
      • Whoever runs the gateway could rewrite the whole record. Only a copy held elsewhere shows it (question 14).
      • Going round the gateway. The data server itself still asks for no key.
